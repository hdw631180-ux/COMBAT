# Shadow Legends

Jeu d'action 2D en vue de profil : 8 mondes, 40 niveaux, boss, 10 héros, forge, missions quotidiennes, succès et options.

## Publier sur GitHub Pages

1. Place `index.html`, `.nojekyll` et `README.md` à la racine de ton dépôt.
2. Sur GitHub : Settings > Pages > Source : "Deploy from a branch", branche `main`, dossier `/ (root)`.
3. Le jeu est disponible à `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/` après une minute environ.

## Commandes

- Déplacement : flèches ou WASD
- Saut : Espace
- Attaque : J
- Compétences : K (Onde de choc), L (Lame spectrale)
- Esquive : Maj
- Pause : Échap (M pour revenir au menu)

La sauvegarde est automatique dans le navigateur.
